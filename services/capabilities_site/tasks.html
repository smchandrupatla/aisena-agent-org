File format

Use a UTF-8 CSV or XLSX file up to 5 MB. Keep every header below in this exact order; only title requires a value.

title,description,owner,status,priority,dependency,next_checkpoint,tags,app_label
Owner: agent key or name; leave blank for automatic assignment Status: To Do, Backlog, Planned, In Progress, Blocked, In Review, or Done Priority: Low, Medium, High, Urgent, or Critical Dependency: existing task ID, for example TASK-000001 Tags: separate values with semicolons; commas are also accepted in quoted CSV cells Task ID: do not add this column; IDs are generated during import
