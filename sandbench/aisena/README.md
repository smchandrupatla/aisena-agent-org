# AISENA Agent Project

A comprehensive AI benchmarking and testing platform for the AISENA agent framework.

## Structure

- `ai_agent_config.yaml` - Configuration for the AISENA agent
- `models/` - Model definitions and weights
- `scripts/` - Training and evaluation scripts
- `benchmarks/` - Benchmark scenarios
- `infrastructure/` - Deployment and infrastructure configurations
- `dev-tools/` - Development utilities

## Quick Start

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure the agent: `ai_agent_config.yaml`
4. Run benchmarks: `python -m benchmarks.run`

## Benchmark Scenarios

The project includes various benchmark scenarios for evaluating agent performance across different tasks.

See `benchmarks/scenarios/` for detailed scenario definitions.
