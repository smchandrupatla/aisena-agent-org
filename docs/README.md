# Docs

Place architecture notes, ADRs, design documents, and runbooks here.

## Core Operating Docs

- **`AI_SENA_OPERATING_INSTRUCTIONS.md`** — **canonical** AI Sena / AISENA operating charter (change pipeline, risk, visibility, config, NFRs, security).
- **`DEVELOPMENT_PRACTICES_AGENT.md`** — coding, testing, and handoff rules for all agents.
- **`OPERATING_INSTRUCTIONS_COMPLIANCE.md`** — Done / Partial / Open status vs the charter.
- `AGENT_OPERATIONS_WIKI.md` — autonomous operating protocol, guardrails, and logging template.
- `AGENT_CHANGE_LOG.md` — append-only execution log of meaningful project actions.
- `AGENTIC_AI_KNOWLEDGE_BASE.md` — comprehensive Agentic AI reference: 10-step roadmap, agent types, agent loop, tools & frameworks, architecture, evaluation metrics, guard types, prompt patterns, common mistakes, and AISENA framework mapping.
- `PROMPTING_STRATEGY_MVP_DELTA.md` — how to scope prompts: one big MVP prompt with explicit non-goals, then small single-feature "delta" prompts for everything after.

Root **`AGENTS.md`** points agents at the documents above.
