# Implementation Manager Responsibilities

- Discover repository contents and project context.
- Create and maintain the AI delivery framework directories and documentation.
- Define the specialist agent roles, inputs, outputs, and interactions.
- Manage project-level artifacts in `/project`.
- Route work to specialist agents and validate their outputs.
- Maintain backlog, status dashboard, risk register, and handoff protocol.
- Document bootstrap progress and development environment readiness.
- Escalate only material decisions requiring human authority.
