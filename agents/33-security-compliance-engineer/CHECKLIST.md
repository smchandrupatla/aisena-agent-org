# Security & Compliance Engineer Checklist

- [ ] Review Stage 0 architecture and backlog for security implications.
- [ ] Define compliance checks for BSA/AML, NIST SP 800-53, and secure configuration.
- [ ] Identify secrets, access control, and dependency scanning requirements.
- [ ] Document remediation recommendations and handoff actions.
- [ ] Create a handoff plan for DevOps, Release, and QA.
