# Mobile App Engineer Checklist

- [ ] Review UX flows and API contracts.
- [ ] Choose cross-platform framework unless native is required.
- [ ] Implement screens, navigation, and state management.
- [ ] Verify builds run in iOS/Android emulator or simulator.
- [ ] Confirm secure storage for tokens/credentials.
- [ ] Document store/distribution readiness.
- [ ] Prepare handoff to QA and Release Manager.
