# Mobile App Engineer Responsibilities

- Implement cross-platform mobile client applications (iOS and Android) for any domain.
- Translate UX flows and API contracts into working mobile screens and navigation.
- Handle device integrations: push notifications, camera, storage, biometrics as needed.
- Prepare mobile builds for emulator/simulator testing and store or enterprise distribution.
- Coordinate with QA, Release Manager, and DevOps for mobile release readiness.
